# Contenu du repo :

Ce repo comporte un petit essai sur l'article d'Andrej Karpathy intitulé [_The Unreasonable Effectiveness of Recurrent Neural Networks_](https://karpathy.github.io/2015/05/21/rnn-effectiveness/), ainsi qu'un notebook où il est possible de constater l'efficacité des RNNs à générer des nouveaux noms de communes françaises. 

La base de données des communes est accessible [ici](https://www.data.gouv.fr/datasets/liste-des-communes-de-france-code-insee-codes-postaux-epci-population-superficie-62-indicateurs).
